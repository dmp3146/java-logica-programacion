# Recursión, algoritmos y complejidad

Después de aprender estructuras de datos, esta etapa conecta estructuras con algoritmos.

## Temas

- Recursión.
- Casos base.
- Búsqueda.
- Ordenamiento.
- Divide y vencerás.
- Backtracking.
- Complejidad temporal.
- Complejidad espacial.
- Notación Big O.

## Objetivo

No basta con que un algoritmo funcione. También aprenderás a preguntarte cuánto tarda, cuánta
memoria utiliza y cómo cambia su comportamiento cuando aumenta el tamaño de los datos.
