# Java - Lógica, Estructuras de Datos y Desarrollo

Este repositorio es una ruta progresiva de aprendizaje en Java.

## Punto de partida

Se eliminó la etapa inicial de fundamentos para comenzar directamente en:

**02-secuencial**

Taller de
Estructura Secuencial comienza con ejercicios de captura de dos valores para calcular suma y
diferencia, seguido por promedio, raíz/cuadrado, porcentajes, conversiones, salarios y otros
problemas. La guía continúa posteriormente con condicionales, CASE/SWITCH, ciclos, suiches/banderas,
vectores, ordenamiento/búsqueda y matrices.

A partir del final de ese material se agregaron etapas de aprendizaje complementarias de Java y
estructuras de datos para convertir la práctica en una ruta completa hacia proyectos.

## Ruta

1. `02-secuencial` — problemas secuenciales.
2. `03-condicionales` — if, else, else-if y condiciones compuestas.
3. `04-case-switch` — switch/case.
4. `05-ciclos` — while, do-while y for.
5. `06-suiches-y-banderas` — centinelas, banderas y procesos alternos.
6. `07-vectores` — arrays de una dimensión.
7. `08-ordenamiento-y-busqueda` — búsqueda y ordenamiento.
8. `09-matrices` — arrays bidimensionales.
9. `10-excepciones` — try/catch, finally, throw y throws.
10. `11-poo` — clases, encapsulación, herencia, polimorfismo e interfaces.
11. `12-colecciones` — ArrayList, LinkedList, HashSet, HashMap, etc.
12. `13-pila` — Stack / implementación propia.
13. `14-cola` — Queue / implementación propia.
14. `15-listas-enlazadas` — nodos y listas.
15. `16-arboles` — árboles binarios y BST.
16. `17-heap-y-priorityqueue` — montículos y colas de prioridad.
17. `18-grafos` — grafos, recorridos BFS/DFS.
18. `19-recursion-y-algoritmos` — recursión, divide y vencerás y complejidad.
19. `20-integracion` — ejercicios que mezclan varias estructuras.
20. `21-apps-finales` — proyectos pequeños para demostrar lo aprendido.

## Regla para cada ejercicio

Cada ejercicio debe intentar seguir:

**Enunciado → análisis → entrada → proceso → salida → pseudocódigo → prueba de escritorio →
diagrama cuando aporte valor → implementación Java → pruebas → revisión → commit.**

No todos los ejercicios necesitan UML ni diagramas. Se utilizarán cuando realmente ayuden a
practicar diseño.

## Meta

La idea no es terminar carpetas rápidamente. La meta es que puedas explicar el código, modificarlo,
detectar errores y después construir aplicaciones por tu cuenta.
