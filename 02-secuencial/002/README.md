# Ejercicio 002 — Estructura secuencial

## Enunciado de la guía

> All Mondays, Wednesdays and Fridays, a person runs the same route and timing the obtained times. Calculate the average time the person takes to travel the road in one week either.

## 2. ¿Qué debo hacer?

El programa debe programa debe solicitar el programa la usuario en minutos.

1. Leer el primer tiempo.
2. Leer el segundo tiempo.
3. Leer el tercer tiempo.

5. Mostrar los resultados en pantalla.

Este ejercicio corresponde a una estructura secuencial, ya que las instrucciones se ejecutan en orden.
